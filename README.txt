STEPTECH WEBSITE — QUICK START

WHAT IS INCLUDED
- index.html: website content and structure
- style.css: colours, layout and responsive design
- script.js: mobile menu and WhatsApp enquiry form

HOW TO OPEN IT
1. Extract the STEPTECH-WEBSITE.zip file.
2. Open the extracted STEPTECH-WEBSITE folder in Visual Studio Code.
3. Open index.html in your browser, or use the Live Server extension in VS Code.

IMPORTANT: SET UP YOUR CONTACT DETAILS BEFORE SHARING THE WEBSITE
1. Open script.js.
2. Find: const WHATSAPP_NUMBER = "2547XXXXXXXX";
3. Replace it with your own WhatsApp number in international format, without + or spaces.
   Example format: 2547XXXXXXXX
4. Find: const BUSINESS_EMAIL = "hello@steptech.example";
5. Replace it with an email address you control.
6. Save the file and test the contact form.

HOW THE CONTACT FORM WORKS
The form opens WhatsApp with the visitor's details and message pre-filled.
The visitor must press Send in WhatsApp. The form does not silently send messages.
This is a front-end contact method; it does not store enquiries in a database.

BEFORE TAKING REAL CLIENTS
- Replace sample contact details with your own.
- Check every link and test on a phone.
- Keep the portfolio concepts labelled as sample concepts until you have real client work.
- Agree on the work, price, delivery date, revisions and payment terms with a customer before starting.
- Do not promise advanced online stores, user accounts or online payments until you have built and tested those features.

PUBLISHING
You can first preview the site on your own computer. To make it public, upload the files to a hosting service. A custom domain is optional and may cost money. Check the hosting provider's current terms and pricing before choosing one.

This starter website is a front-end business site, not a full e-commerce system or a server-backed booking platform.
